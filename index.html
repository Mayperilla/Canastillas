⚙️ Configuración Inicial

Sistema de Control de Canastillas con Google Sheets

📋 Pasos para Configurar

  1. Ve a Google Cloud Console
  2. Crea un proyecto nuevo (ej: "control-canastillas")
  3. Habilita Google Sheets API
  4. Crea credenciales → Clave de API
  5. Crea credenciales → ID de cliente OAuth 2.0
  6. En OAuth, agrega origen autorizado: http://localhost o tu dominio
  7. Crea una hoja de Google Sheets y obtén su ID
Tu clave de API de Google Cloud Console
Tu ID de cliente OAuth 2.0
El ID está en la URL de tu hoja: docs.google.com/spreadsheets/d/[ID_AQUI]/edit

❓ Ayuda Rápida

¿Cómo crear la Google Sheet?

1. Ve a Google Sheets

2. Crea una hoja nueva llamada "Control Canastillas"

3. En la primera fila pon: Fecha | Hora | Proveedor | Supermercado | Cantidad | ID_Entrega | ID_Recepcion

4. Comparte la hoja con "Cualquier persona con el enlace" puede editar

5. Copia el ID de la URL

¿Qué permisos necesito?

La API Key necesita tener habilitada Google Sheets API

El OAuth necesita el scope: https://www.googleapis.com/auth/spreadsheets
